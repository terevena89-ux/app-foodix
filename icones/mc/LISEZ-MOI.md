# Textures Minecraft pour Foodix

Déposer ici des images **PNG carrées** (16×16 comme dans le jeu ; 32×32 marche aussi), nommées **exactement** comme dans les tableaux ci-dessous (minuscules, sans accent).

- Un fichier présent remplace le dessin de Foodix. Un fichier absent : Foodix garde son dessin d'origine. On peut donc en mettre quelques-uns pour commencer.
- Pour voir ce qui est reconnu : ouvrir la page `icones/mc/` de l'appli (l'adresse de Foodix suivie de `icones/mc/`).
- Après un ajout : recharger l'appli (les fichiers absents ne sont redemandés qu'au rechargement).

## Où trouver les textures

Un fichier `.jar` (le jeu ou un mod) s'ouvre comme un `.zip`. Les objets sont dans `assets/<nom du mod>/textures/item/`.

- Jeu : `.minecraft/versions/<version>/<version>.jar` → `assets/minecraft/textures/item/`
- Mod : `.minecraft/mods/<mod>.jar` → par exemple `assets/farmersdelight/textures/item/`

Copier le fichier ici et le **renommer** avec le nom de la colonne de gauche.

> Ces textures appartiennent à Mojang et aux auteurs des mods. Le dépôt de Foodix est public : les déposer ici les republie. Pour un usage strictement personnel, mieux vaut passer le dépôt en privé, ou vérifier la licence de chaque mod.

Les suggestions ci-dessous sont données de mémoire : le nom exact peut changer selon la version du jeu ou du mod. « — » = rien dans le jeu ni dans Farmer's Delight, à chercher dans un autre mod de cuisine (Croptopia, Pam's HarvestCraft 2…).
